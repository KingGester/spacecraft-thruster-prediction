# 🚀 داشبورد پیش‌بینی رانش/شتاب Thruster Forecast Dashboard

این داشبورد روی **Streamlit** ساخته شده و بدون **Deep Learning** با مدل‌های **XGBoost** آماده‌شده‌ی همین پروژه کار می‌کند.

## پوشه‌ها
- `models/` شامل:
  - `xgb_final_model.joblib` (مدل سراسری)
  - `models/individual/xgb_model_*.joblib` (مدل‌های اختصاصی SN)
- `dashboard/app.py` اسکریپت اصلی داشبورد
- `src/forecast.py` توابع کمکی ساخت ویژگی و پیش‌بینی چند-گام جلوتر

## نصب و اجرا
```bash
# ایجاد محیط (اختیاری اما توصیه شده)
python -m venv .venv
# فعال‌سازی (Windows)
.venv\Scripts\activate
# یا (Linux/Mac)
source .venv/bin/activate

# نصب پیش‌نیازها
pip install -r requirements.txt

# اجرای داشبورد
streamlit run dashboard/app.py
```

## ورودی لازم
یک فایل CSV با حداقل ستون‌های زیر:
- `thrust` — نیروی رانش مشاهده‌شده (N)
- `ton` — گذر زمان از لحظه روشن شدن (ثانیه)
- `on_duration` — مدت زمان روشن بودن در هر گام (ثانیه)
- `timestamp` (اختیاری)



## خروجی
- نمودار و جدول **پیش‌بینی رانش** چند ثانیه‌ی آینده
- در صورت وارد کردن جرم (kg)، **شتاب** (`a = F / m`) نیز نشان داده می‌شود
- امکان **دانلود CSV** خروجی

## نکات طراحی
- پیش‌بینی چند-گام جلوتر به‌صورت **recursive** انجام می‌شود: خروجی هر گام به عنوان ورودی گام بعدی استفاده می‌شود.
- ویژگی‌ها همان‌هایی هستند که در آموزش مدل استفاده کرده‌اید: `ton, on_duration, lag_thrust_1, rolling_avg_thrust, cumulative_on_time`.
- برای سناریو آینده، می‌توانید `on_duration` را ثابت نگه دارید یا اجازه دهید با Δt افزایش یابد.
- اگر به عدم‌قطعیت نیاز دارید، می‌توانیم در نسخه بعدی باند خطا بر اساس MAE اعتبارسنجی اضافه کنیم.
